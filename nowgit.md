## Notes

- Secrets never enter the repository: `.env`, `GLMProxySecret.txt`, `keytext*.md`, `COMPETITOR_REPORT.md` and `app_audit*.md` are gitignored.
- The GLM dev key is present only in the local working copy and is excluded from Release builds via `EXCLUDED_SOURCE_FILE_NAMES` / `EXCLUDED_RESOURCE_FILE_NAMES`.
- Production cloud AI uses StoreKit 2 subscription JWS, so no shared secret ships to the App Store.
